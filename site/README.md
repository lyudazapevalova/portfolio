# Первый макет портфолио

Версия 0.1 · 14 октября 2026.

## Состав
- Главная: представление, Finelo, список будущих кейсов, обо мне, контакты.
- Отдельная страница Finelo с реальными экранами из Figma.
- Полные RU / EN версии обеих страниц.
- Адаптивная вёрстка, увеличение экранов, навигация по кейсу.
- Мерцание скелетона на CSS; пауза и учёт системной настройки уменьшения движения.

Остальные проекты пока ведут на Behance. Иви показан без ссылки — материал ещё не получен.

## Продолжение работы
Исходники сайта находятся в `dist/`: `index.html`, `finelo.html`, `app.js`, `style.css`, `assets/`.
Структура и русские тексты записаны в соседней папке `../project-docs/`.
Это первая визуальная итерация, а не утверждённый финальный дизайн. Сначала собираем замечания к главной и Finelo, затем оформляем остальные кейсы по одному, начиная с Иви.

## Локальный запуск
Из папки `dist` запустите `python3 -m http.server 8765`, затем откройте http://127.0.0.1:8765/ .
Можно открыть index.html напрямую. Ссылки, смена языка и увеличение экранов работают без сервера.
Шрифт Manrope загружается из Google Fonts, при недоступности используется системный шрифт.

## Важное для следующего чата
- Не создавать новый Site: использовать project_id из `.openai/hosting.json`.
- Нельзя приписывать Люде все экраны вводной галереи. Её работа начинается отдельным блоком.
- Метрики поддержки относятся к исходному тесту доступа к поддержке, не к чату.
- Не возвращать перенос апселлов после онбординга, email-кампанию и формулировки об отсутствии аналитики в публичный текст.
- Пример spotlight-онбординга ждёт скриншотов и пока не показан.
- Анимация скелетона — демонстрация на основе исходного экрана и параметров Figma, не запись приложения.
