# Портфолио Люды Запеваловой

Основная папка проекта: /Users/ludmilazapevalova/Documents/portfolio.

- site/dist/ — исходники и изображения сайта: index.html, finelo.html, app.js, style.css, assets/.
- site/README.md — инструкция запуска и статус размещения.
- site/previews/ — снимки макетов.
- project-docs/ — подробный план, тексты, решения, ссылки на Figma и исходники резюме.

Для продолжения в новом чате используйте эту папку как проект. Сначала прочитайте project-docs/README.md. Правьте сайт в site/dist/ и обновляйте документы по мере изменений.

Прежние пути в папке чата Documents/Codex сохранены как ссылки на эти папки: локальный предпросмотр продолжает читать те же исходники, отдельной копии сайта нет.
