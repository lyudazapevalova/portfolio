# Первый макет портфолио

Версия 0.1 · 14 октября 2026.

## Состав
- Главная: представление, Finelo, список будущих кейсов, обо мне, контакты.
- Отдельная страница Finelo с реальными экранами из Figma.
- Полные RU / EN версии обеих страниц.
- Адаптивная вёрстка, увеличение экранов, навигация по кейсу.
- Мерцание скелетона на CSS; пауза и учёт системной настройки уменьшения движения.

Остальные проекты пока ведут на Behance. Иви показан без ссылки — материал ещё не получен.

## Продолжение работы
Исходники сайта находятся в `dist/`: `index.html`, `finelo.html`, `app.js`, `style.css`, `assets/`.
Структура и русские тексты записаны в соседней папке `../project-docs/`.
Это первая визуальная итерация, а не утверждённый финальный дизайн. Сначала собираем замечания к главной и Finelo, затем оформляем остальные кейсы по одному, начиная с Иви.

## Локальный запуск
Из папки `dist` запустите `python3 -m http.server 8765`, затем откройте http://127.0.0.1:8765/ .
Можно открыть index.html напрямую. Ссылки, смена языка и увеличение экранов работают без сервера.
Шрифт Manrope загружается из Google Fonts, при недоступности используется системный шрифт.

## Важное для следующего чата
- Не создавать новый Site: использовать project_id из `.openai/hosting.json`.
- Нельзя приписывать Люде все экраны вводной галереи. Её работа начинается отдельным блоком.
- Метрики поддержки относятся к исходному тесту доступа к поддержке, не к чату.
- Не возвращать перенос апселлов после онбординга, email-кампанию и формулировки об отсутствии аналитики в публичный текст.
- Пример spotlight-онбординга ждёт скриншотов и пока не показан.
- Анимация скелетона — демонстрация на основе исходного экрана и параметров Figma, не запись приложения.

## Уточнения v0.4 — 14 октября 2026

Второй цветок нежно-розовый, с цельным плавным контуром лепестков. Размеры обоих цветов одинаковы: 68 px desktop / 48 px mobile. Оба вращаются при наведении и плавно замедляются после ухода указателя; reduced motion отключает вращение. Переходы карточек и тегов — 320 ms с мягкой кривой cubic-bezier(.4,0,.2,1). У ссылок футера есть изменение цвета и подчёркивание при наведении и фокусе с клавиатуры.

## Начало кейса v0.6 — 14 октября 2026

Последние замечания Люды заменяют прежние решения о CEO и написании Learning Designers в русской версии: CEO убран, используется «Learning дизайнеры» и «продакт-менеджер». Период работы не показывается. Вступление слева, команда отдельной лавандовой плашкой справа. Теги как на главной; внешние ссылки с цветом и подчёркиванием при наведении. Первый коллаж и отдельный экран пути обучения удалены.

Меню: «Как устроен Finelo», «Мои задачи», «Поддержка», «Web → App», «Дополнения к подписке», «Исследования», «Дизайн-система». Кликабельные капсулы 14 px.

В обзоре продукта: заголовок раздела, затем три подраздела. У каждого подзаголовок слева, основной текст 16 px справа, ниже серия экранов. На mobile текст последовательный. Уроки: quiz/practice/feedback на мятном поле; игровые механики: complete/streak/leaderboard на персиковом; инструменты: tools/simulator/mentor на голубом. Tool page экспортирован по прямой ссылке Люды: https://www.figma.com/design/Lg3I8QQ1hfHaaMh4Nc7YBi/finelo?node-id=1-458697 .

Изображения только в обзоре продукта раскрываются плавно из исходной карточки, целиком помещаются на экране и возвращаются обратно при закрытии. Стрелки и кнопка закрытия скрыты; закрытие кликом вне изображения или Esc. При reduced motion переход мгновенный. Тексты и визуалы начиная с раздела contribution не изменены; там сохраняется прежний lightbox.

В полноэкранном просмотре открывается исходный экран 375 × 872.

Навигация: 14 px desktop / 13 px mobile. При наведении только цвет; линия только у активного раздела, ближе к тексту. «Мои задачи» переименованы в «Мой вклад». Вместо большого рекламного заголовка — название раздела и body-описание 16 px.

Страница work: https://www.figma.com/design/Lg3I8QQ1hfHaaMh4Nc7YBi/finelo?node-id=2017-51397 . Представлены все четыре задачи, по нескольку экранов: магазин (3), обновления (2), локализация стор-скринов (3), первый вход (1). Плашки шириной 7/12 и 5/12 сетки; экраны скруглены. На mobile задачи друг под другом, большие серии прокручиваются внутри плашек. Lightbox сетки использует такое же раскрытие/закрытие, как обзор продукта.

## Finelo v0.9 — 14 октября 2026

В «Моём вкладе» все четыре плашки одинакового размера, на desktop сетка 2 × 2. Все девять экранов имеют одинаковую ширину и высоту; подписи 13 px desktop / 12 px mobile, обычное начертание. На mobile одинаковые плашки расположены друг под другом, длинные серии прокручиваются. Обзор продукта не менялся.

Стор-скрины с разными сюжетами: английский — уроки (2020:53543), французский — инструменты анализа (2020:54822), арабский — лидерборд (2020:56068). Приветствие заменено светлым вариантом 2020:60631.

Подсветка меню сразу следует выбору пользователя и сохраняется на время перехода; после завершения прокрутки активный раздел определяется по верхней границе секций. У выбранной ссылки aria-current=location. Старый IntersectionObserver для подсветки заменён.
