# Ozon — план подготовки кейса

Обновлено: 16 октября 2026.
Статус: создан локальный визуальный вариант ozon.html в RU/EN и карточка на главной. Подача одобрена для пробы; итоговый вид ожидает просмотра Людой. Публикация не выполнялась.

## Структура v0.4

1. Введение: название, одно предложение о проекте, краткий паспорт.
2. Задача: проблема, что нужно сделать и одна строка сигналов из брифа.
3. Итоги исследования: интервью, конкуренты, HMW и выбор идей — один блок. Три короткие связи «находка → идея».
4. Юзабилити-тестирование: что проверяла, что сработало и что было непонятно.
5. Готовый интерфейс: три сценария с крупными макетами и короткими пояснениями.
6. UI kit: один абзац и компактный пример компонентов.
7. Если бы решение запускали в продукте: действия в гипотетическом продуктовом запуске, без повторения списка метрик.
8. Контакты.

Отдельные «Что происходило на главной» и «Задача и критерии успеха» объединены в один короткий блок «Задача». Таблица метрик удалена, сигналы упоминаются один раз. Отдельные разделы исследовательских вопросов, находок, HMW, идеации и приоритизации объединены в итоги исследования. Вклад показывается глаголами действий по ходу истории.

Самое важное должно считываться по заголовкам, схеме исследования, результатам теста и сериям экранов. Подробный рассказ о каждом методе не нужен. У финальных сценариев 1–2 предложения. Конкретного обязательного числа слов нет: v0.4 значительно короче v0.2, повторы и отвлечённые объяснения убраны.

До готового интерфейса предлагаем визуализировать реальные выводы исследования и тестирования. Это редакционная подача существующих фактов, не новый ресерч и не новые скриншоты прототипа. Низкодетализированные макеты по-прежнему исключены. Люда одобрила попробовать небольшую обложку из финальных экранов в начале; она включена в локальную страницу.

## Общие правила для следующих кейсов

- Карточка: название, теги, несколько финальных экранов, короткое описание задачи, личный вклад.
- Общий визуальный язык: заголовки, описания, серии макетов, типографика, интервалы и поведение. Названия и порядок содержательных блоков выбираются под историю каждого кейса.
- Учебный формат отмечать спокойно в паспорте; основная история — реальная продуктовая задача из брифа.
- Учебные брифы — курс «Продуктовый дизайнер+» Bang Bang Education, по словам Люды в сотрудничестве с компаниями. Факты каждого следующего проекта проверять по его материалам.
- Пастельная основа сайта сохраняется, цвета галерей могут отсылать к проекту. Для Ozon предложены светлые голубой, лавандовый и розовый.
- Просмотр, закрытие, анимация, reduced motion и скругления общие с Finelo.
- Изменилась очерёдность подготовки: сейчас Ozon. Порядок карточек на сайте пока не меняем.

## Ozon v20 — 16 октября 2026

Инсайты без изображений: под каждым по две идеи с объяснением пользы. Задача переписана по брифу: непонятный первый шаг, высокая нагрузка, отсутствие персонализации. Схема уменьшена, стрелки рассчитываются от исходных элементов главной к соответствующим страницам; снизу сохранён отступ. Перед итогами — границы проверки прототипа. Итоги обобщены по выводам Figma 14128:20041. UI kit: скруглён таббар, карточка центрирована, бейдж не обрезается; увеличение компонентов отключено, hover-анимация сохранена.
