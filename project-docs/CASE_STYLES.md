## Где применять

Описание использует case-description, заголовки разделов — section-title, названия и описания серий — product-caption, подписи — общий стиль screen-caption / support-flow figcaption. Дополнительные локальные уменьшения этих элементов не вводить. Web → App не имеет отдельного размера заголовка.

## Сохранённые особенности

- Состав и сетка шапки Finelo с командой; вертикальное расположение паспорта Ozon на мобильном.
- Колонки, порядок и размеры экранов, внутренние поля и промежутки конкретных галерей, UI kit и схемы прототипа.
- Пастельные цвета, исследовательские записки, карточки результатов и другие уникальные блоки Ozon.
- Положение подписей схемы сверху экранов. Шрифт общий; высота подписи может меняться при переносе текста.
- По уточнению v29 над завершением всех локальных кейсов есть общий разделитель, как у Finelo. Прежнее исключение Ozon отменено.
- Все анимации, hover-поведение и reduced motion каждого кейса. Прототип Ozon остаётся неподвижным при наведении, чтобы сохранялась привязка стрелок; увеличение по клику работает как прежде.

## Шапка Ozon

Вводное описание прямо называет Ozon маркетплейсом в RU и online marketplace в EN. По уточнению v28 логотип заменяет видимое текстовое название в H1: синий знак без фоновой плашки, как на присланном образце. Контейнер H1 использует общую типографику, высота изображения — .7em; доступное название Ozon сохранено. Это прямое согласованное исключение для брендового названия. ## Переходы между кейсами — v29

Порядок берётся из общего каталога: Finelo → Иви → Ozon → Звук → CinemaPark → Plate Planner. У первого кейса одна кнопка следующего по центру. У остальных — предыдущий слева и следующий справа, включая мобильную сетку в две колонки. Расстояние между стрелкой и текстом — 8 px. Подписи RU/EN включают название кейса. Активны только переходы к существующим страницам сайта; они сохраняют язык. Если локальной страницы нет, кнопка с названием соседнего кейса неактивна и имеет подсказку «Кейс готовится». В текущей навигации это Иви и Звук. Ссылки Behance из каталога работ здесь не используются.

Уточнение мобильной навигации v29: подписи сокращены до «Предыдущий кейс: название» / «Следующий кейс: название» (Previous case / Next case), чтобы сохранить две колонки и читаемость; до 360 px шрифт кнопок 12 px. Название соседа есть на каждой кнопке.
